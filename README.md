# prosto-holst — сайт-витрина мастерской «Просто Холст»

Одностраничник-визитка для мастерской холстов и рам в СПб (пл. Ленина, 3).
Без сборки: чистые HTML + CSS + JS. Открыть `index.html` — и всё работает.

## Структура

```
index.html        — вся страница
assets/style.css  — стили (палитра и шрифты — в :root сверху)
assets/main.js    — reveal-анимации и год в футере
```

## Что заменить на реальные данные

- **Фото мастерской** — секция «Мастерская» (`#shop`): четыре слота-заглушки
  `.shot`. Внутрь `<li>` вместо `<div class="shot__ph">фото</div>` положите
  `<img src="..." alt="...">`.
- **Телефон / ссылки** — ищутся по номеру `+7 910 714-82-25` и адресам
  `wa.me`, `avito.ru/brands/...`, `vk.ru/prostoholstspb`, `instagram.com/prostoholst_spb`.
- **Цены** — секция «Цены» (`#price`), взяты с Авито на сентябрь 2026.

## Шрифты

Google Fonts: Rubik Mono One (заголовки), Golos Text (текст),
JetBrains Mono (размеры, цены, метки). Подключены через `<link>` в `index.html`.

## Хостинг

Статика — куда угодно: GitHub Pages, Netlify, Cloudflare Pages.
Главная кнопка ведёт на Авито, WhatsApp — вторая точка входа.
