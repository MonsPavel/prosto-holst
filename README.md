# Просто холст

Лендинг мастерской Максима Стукалина, Санкт-Петербург. Статический HTML/CSS/JS без внешних зависимостей. Шрифты и бренд-графика размещены локально.

## Запуск

Требуется Node.js. `npm run dev` открывает сервер на http://127.0.0.1:4173. Установка зависимостей не нужна. `npm run check` проверяет локальные ресурсы, якоря, атрибуты изображений и синтаксис JavaScript.

Готовый сайт находится в `dist/`. Его можно разместить на любом статическом хостинге. `scripts/serve.mjs` предназначен для локального просмотра.

Все тексты и ссылки находятся в `dist/index.html`; оформление — в `dist/styles.css`. `dist/script.js` раскрывает нужную услугу при переходе по ссылке.

## Дизайн

В основе — фирменный рисунок скейта, выходящего за края рамы. Бумага `#f8f0e4`, чернила `#191919`, кобальт `#2449e8`, приглушённый текст `#68645f`, второй бумажный фон `#eee8df`. Oswald для плакатных заголовков, Golos Text для чтения. Короткая асимметричная витрина: рисунок и призыв на первом экране, услуги, автор, контакты.

Аккордеоны работают с клавиатуры и без JavaScript. Якоря ведут к соответствующей услуге. Есть мобильные стили, явный фокус и учёт prefers-reduced-motion. Формы, сбор данных, аналитика и платежи не подключены.
